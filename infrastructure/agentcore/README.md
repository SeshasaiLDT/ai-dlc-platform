# AgentCore Gateway stack

`gateway.json` is generated from the Python handler catalogs by `generate.py`. Deploy it with CloudFormation after supplying the existing runtime role name plus the three same-account, same-region governed target Lambda function names and their execution role names. The stack also creates a short-lived DynamoDB invocation table and scoped runtime/target access policies. The authenticated runtime must issue one-use references into that table; each target consumes them atomically and re-resolves authorization. Target deployments and the packaged runtime remain prerequisites; see [architecture](../../docs/architecture/agentcore-gateway.md).

Validate drift locally with `PYTHONPATH=src .venv/bin/python infrastructure/agentcore/generate.py` followed by `git diff --exit-code -- infrastructure/agentcore/gateway.json` (or run `pytest -q tests/test_gateway.py`). The stack requires `CAPABILITY_IAM` at deployment. A live `aws cloudformation validate-template` needs AWS CLI/network access and a supported AgentCore region.
