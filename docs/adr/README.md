# Architecture Decision Records

Architecture Decision Records (ADRs) capture significant technical decisions.

## Required sections

Each ADR must include:
- Status
- Context
- Decision
- Alternatives considered
- Consequences
- Revisit triggers

## Status values
- Proposed
- Accepted
- Superseded
- Rejected
- Deprecated

## Naming
`ADR-NNN-short-title.md`
